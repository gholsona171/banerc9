# Cloud 9 RP banner and logo

Public images for the Cloud 9 RP FiveM server. FiveM loads the banner from here, so this repo must
stay public and must never contain anything private.

| File | Used for |
|---|---|
| `banner.gif` | `banner_detail` and `banner_connecting` in the server's `server.cfg` (animated, 1000x334: "CLOUD NINE" in chrome as the focal point with an RP badge, letters hop in a wave; the city from the still banner drifts behind it) |
| `banner-wide.webp` | Still version of the banner |
| `logo.webp` | Square logo |
